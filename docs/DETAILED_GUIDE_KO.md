## 1. 앱 소개

**Ride the World – Indoor Cycling**은 다음을 위한 앱입니다.

- **실제 지도 위에서** 자전거/도보/자동차 경로를 계획하고
- **고도(표고)** 를 확인하며
- **거리뷰(Street View)** 로 실제 풍경을 보면서
- **실내에서** 선택한 속도로 주행을 시뮬레이션하는 것

데이터 출처: 지도(OpenStreetMap), 경로(OSRM), 표고(Open-Elevation API) 등이 사용됩니다.

---

## 2. 처음 시작하기

- 앱을 열면 **지도**가 로드됩니다.
- 화면 **왼쪽 아래**에 **경로 설정** 패널이 있습니다. (접혀 있으면 **경유지 아이콘**을 눌러 펼칩니다.)
- **출발(Start)** 과 **도착(End)** 두 곳을 정하면 경로를 검색할 수 있습니다.

**방법 1: 직접 입력**  
- "Start" 칸에 출발지, "End" 칸에 도착지를 입력하면 **자동완성 추천**이 나타납니다.  
- 추천 목록에서 항목을 선택하거나, 키보드 ↑/↓로 이동 후 Enter로 선택할 수 있습니다.

**방법 2: 지도 클릭**  
- 지도나 경로 위의 **아무 위치**를 클릭하면 해당 지점의 **주소·좌표·표고**가 팝업으로 표시됩니다.  
- 팝업에서 **START (A)** / **WAYPOINT** / **END (B)** 버튼으로 출발지, 경유지, 도착지를 지정할 수 있습니다.

---

## 3. 경로 설정

### 3.1 출발·도착·경유지

| 입력란 | 설명 |
|--------|------|
| **Start (파란 점)** | 출발지. 주소 입력 또는 지도 클릭 후 "START (A)" 선택 |
| **End (빨간 점)** | 도착지. 주소 입력 또는 지도 클릭 후 "END (B)" 선택 |
| **Waypoint** | 경유지. 최대 **3개**까지. 지도 클릭 후 "WAYPOINT"로 추가 |

- 각 입력란 오른쪽 **X** 버튼으로 해당 출발/도착/경유지를 지울 수 있습니다.
- 경유지는 순서대로 1, 2, 3 번호로 표시됩니다. 삭제 시 해당 번호만 제거됩니다.

### 3.2 경로 모드 (자동차 / 자전거 / 도보)

출발과 도착을 정한 뒤 다음 세 가지 중 하나를 선택합니다.

- **자동차(Car)** – 자동차 경로
- **자전거(Bike)** – 자전거 경로
- **도보(Foot)** – 도보 경로

선택한 모드에 따라 경로와 예상 거리·시간이 바뀝니다. **Go**를 누르기 전에 원하는 모드를 선택하세요.

### 3.3 기타 경로 버튼

- **↕ (화살표)**  
  출발과 도착을 **바꿉니다**. (A↔B)

- **★ (별)**  
  현재 경로를 **즐겨찾기(My Routes)**에 저장합니다.  
  - 이미 저장된 경로면 별이 채워진 상태로 표시됩니다.  
  - 즐겨찾기는 **최대 5개**까지 저장 가능합니다.

- **휴지통**  
  현재 경로와 마커를 **삭제**합니다. 출발/도착 입력은 유지됩니다.

### 3.4 거리·시간

경로가 계산되면 **거리(km)** 와 **예상 시간**이 경로 설정 영역에 표시됩니다.  
주행 시 사용하는 **속도**에 따라 실제 체감 시간이 달라집니다.

---

## 4. 주행 모드와 속도

### 4.1 속도 설정 (10~70 km/h)

- **숫자 입력칸**: 10~70 사이 값을 직접 입력할 수 있습니다.
- **− / + 버튼**: 1 km/h 단위로 감소/증가합니다.
- **슬라이더**: 드래그해서 속도를 조절합니다.

이 속도는 **시뮬레이션 주행 속도**입니다. 실내 자전거에서는 자신의 페달 강도로 이 속도에 맞춰 타면 됩니다.

---

## 5. 주행 시작과 컨트롤

### 5.1 Go 버튼

- 출발·도착을 입력하고, **경로가 표시된 상태**에서 **Go** 버튼을 누릅니다.
- **처음 경로 검색 시**: 경로 검색 → 거리뷰 준비 → **3, 2, 1, Start!** 카운트다운 후 주행이 시작됩니다.
- **같은 경로를 다시 탈 때**: 카운트다운만 하고 바로 주행이 시작됩니다.

### 5.2 주행 중 컨트롤 (표고 패널 안)

표고 패널이 펼쳐져 있을 때 다음 버튼을 사용할 수 있습니다.

| 버튼 | 기능 |
|------|------|
| **▶ (Play)** | 주행 **시작** 또는 **재개** |
| **⏸ (Pause)** | 주행 **일시정지** |
| **↺ (Restart)** | 경로 **처음부터** 다시 시작 |
| **■ (Stop)** | 주행 **완전 정지** (위치·시간 초기화) |

- **진행 거리**와 **경과 시간**이 표고 패널 상단에 표시됩니다.
- 주행 중에는 지도 위 **마커**가 현재 위치를 보여 주며, 거리뷰가 켜져 있으면 화면에 해당 구간의 거리뷰가 나옵니다.

---

## 6. 거리뷰(Street View)

### 6.1 거리뷰 켜기/끄기

- 화면 **오른쪽 위**의 **거리뷰 아이콘** 버튼을 누르면 거리뷰가 **켜지거나 꺼집니다**.
- 켜면 화면 상단(또는 전체 화면)에 경로 상의 실제 거리뷰가 재생됩니다.

### 6.2 전체 화면 / 축소

- 거리뷰가 켜진 상태에서 **확대/축소 아이콘** 버튼을 누르면  
  **전체 화면 ↔ 상단 절반 + 하단 지도** 레이아웃이 전환됩니다.
- 전체 화면일 때는 작은 **미니 맵**이 한쪽에 표시됩니다.

### 6.3 거리뷰 커버리지 표시

- **경로(라우트) 아이콘** 버튼을 누르면, **거리뷰가 가능한 도로**가 지도 위에 표시됩니다.
- 파란색으로 표시된 구간은 거리뷰를 볼 수 있는 구간입니다.  
  일부 구간에는 거리뷰가 없을 수 있으며, 그럴 경우 "No Street View available for this section." 안내가 나올 수 있습니다.

### 6.4 사용자 제작 이미지

- Google 공식 이미지가 없는 곳에서는 **사용자가 올린 파노라마**가 사용될 수 있습니다.  
  이때 "사용자 제작 이미지" 문구가 표시됩니다.

## 7. 표고 차트와 위치 이동

### 7.1 표고(고도) 차트

- 경로가 있으면 화면 **오른쪽 아래**에 **표고 차트** 패널이 나타납니다.
- **차트 아이콘** 또는 **화살표**를 눌러 패널을 **펼치거나 접을** 수 있습니다.
- 차트에는 경로 전체의 **고도 변화**가 표시되고, **흰색 세로선**이 **현재 주행 위치**를 가리킵니다.

### 7.2 구간 이동 (Step back / Fast forward)

- 표고 차트 양쪽의 **◀ / ▶** 버튼으로  
  **현재 위치를 경로 상에서 앞뒤로 한 번에 여러 포인트**만큼 이동할 수 있습니다.
- 재생을 멈춘 뒤 원하는 구간으로 이동해 다시 재생할 때 유용합니다.

---

## 8. Smart 코칭과 음악

### 8.1 Smart 코칭

- 주행 중 **코칭이 켜져 있으면** 경사·속도 등에 맞춰 **팁(자세, 저항, 강도 등)** 이 표시됩니다.
- **마이크 아이콘** 버튼으로 코칭을 **켜기/끄기**할 수 있습니다.
- **말풍선 아이콘** 버튼으로 코칭 **문구 표시 여부**만 숨기거나 보이게 할 수 있습니다.

### 8.2 배경 음악

- **음악 아이콘** 버튼으로 **배경 음악**을 켜거나 끌 수 있습니다.
- 주행 중 흐름에 맞춰 음악을 활용하면 됩니다.

## 9. 장소 검색과 즐겨찾기

### 9.1 장소 검색

- 화면 **왼쪽 위**의 **돋보기** 버튼을 누르면 **검색창**이 펼쳐집니다.
- "Search place..."에 장소명이나 주소를 입력한 뒤 **Enter**를 치면 지도가 해당 위치로 이동하고 마커가 표시됩니다.
- 검색한 장소는 **Recent** 목록에 저장되며, 나중에 같은 검색어를 빠르게 선택할 수 있습니다.

### 9.2 My Routes (즐겨찾기 경로)

- **경로 설정 패널**을 펼친 상태에서 오른쪽으로 패널을 더 넓히면 **My Routes** 영역이 보입니다.
- **최대 5개**의 경로를 저장할 수 있습니다.
- **저장**: 출발·도착(·경유지)을 넣고 경로를 만든 뒤 **★** 버튼을 누릅니다.
- **불러오기**: My Routes 목록에서 원하는 경로를 클릭하면 해당 출발·도착·경유지가 바로 적용되고, 저장된 경로가 있으면 경로가 복원됩니다.
- **삭제**: 목록에서 각 경로 옆 **X** 버튼(마우스를 올리면 보임)을 누르면 해당 즐겨찾기가 삭제됩니다.

### 10 지도 스타일

- 화면 **오른쪽 위**의 **레이어 아이콘**을 누르면 **일반 지도 ↔ 위성/지형 혼합(hybrid)** 이 전환됩니다.
