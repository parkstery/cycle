# Ride the World Pro - Step 5 함께 달리는 느낌 중심 UX

## UX 원칙
- 거리뷰는 몰입 배경 역할
- 경쟁 정보는 HUD/미니맵/이벤트 레이어로 전달
- 화려한 3D 대신 즉각 피드백과 비교 체감을 우선

## HUD 필수 항목
- 현재 순위
- 앞/뒤 라이더와 거리 또는 시간 갭
- 남은 거리
- 현재 속도/평균 속도

## 소셜 이벤트
- 라이더 입장/퇴장 알림
- 카운트다운 시작/출발 알림
- 추월/피추월 알림
- 간단 퀵 리액션(응원/파이팅)

## 고스트/리플레이
- 비교 대상: 내 PB 또는 최근 동일 코스 기록
- 표시 방식: 현재 위치 대비 +m/-m 혹은 +s/-s
- 결과 화면에서 구간별 페이스 비교 제공

## 정기 이벤트 템플릿
- 예: `매일 20:00 한강 10km`
- 방장 템플릿 저장 후 반복 개설
- 참여자에게 사전 알림(푸시/인앱)

## 완료 기준
- “같이 달린다” 체감을 만드는 우선순위 기능이 확정된다.
- 지도의 작은 점 중심 UI에서 HUD 중심 경쟁 UI로 전환 기준이 명확해진다.
