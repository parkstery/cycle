# 260430-장소검색 및 Start/End 자동완성 드롭다운 처리과정 보고서

## 1) 목적
- 상단 장소 검색과 Route Settings 내 Start/End 입력의 자동완성 UX를 통일하고,
- 검색 결과 선택 시 지도 이동 동작을 명확히 하며,
- 모바일 화면(패널 접힘/키보드 표시)에서도 드롭다운 가시성을 유지하는 것을 목표로 한다.

## 2) 적용 범위
- 파일: `App.tsx`
- 데이터 소스: `services/nominatim.ts`의 `searchSuggestions()` 및 `search()`
- 대상 UI:
  - 상단 장소 검색 입력창
  - Route Settings 패널의 Start/End 입력창 자동완성 드롭다운

## 3) 기존 구조 요약
- Start/End 입력창은 이미 Nominatim 기반 자동완성(`searchSuggestions`)을 사용하고 있었음.
- 상단 장소 검색은 초기에는 Enter 기반 단건 검색(`search`) 중심으로 동작했음.
- 자동완성 드롭다운 폭 확대 후, 패널 우측이 접힌 상태에서 상위 컨테이너의 `overflow-hidden` 영향으로 우측이 잘리는 현상이 발생함.

## 4) 처리 과정

### 4-1. 상단 장소 검색 자동완성 추가 및 지도 이동 연동
- 상단 검색 입력에도 Nominatim 자동완성 목록을 연결함.
- 키보드 동작(ArrowUp/Down, Enter, Escape)과 마우스 선택 동작을 추가함.
- 추천 항목 선택 시:
  - 지도 중심 이동 + 줌 적용
  - 검색 마커(`P`) 표시
  - 최근 검색어 저장/갱신

### 4-2. 검색 마커(`P`) 인터랙션 정리
- 초기 보강안으로 `P` 옆 `X` 오버레이 닫기 버튼을 붙였으나,
- 후속 요구에 맞춰 오버레이 방식은 제거하고,
- `P` 마커 자체 클릭 시 해당 마커가 제거되도록 단순화함.

### 4-3. 검색 후 상단 패널 자동 닫기
- 장소 검색으로 실제 이동이 완료되면 상단 검색 패널(최근 검색 리스트 포함)을 자동으로 닫도록 반영함.
- 목적: 검색 완료 후 패널이 열린 채 남아 시야를 가리는 문제 방지.

### 4-4. Start/End 드롭다운 폭 조정 이력
- 요청에 따라 폭을 순차 조정:
  - 1.5배 확대
  - 추가 30% 확대 + 좌측 정렬
  - 이후 현재 값으로 80% 비율 축소(현재 `w-[156%]`)

### 4-5. 패널 접힘 상태에서 드롭다운 잘림 해결
- 원인: Route Settings 상위 컨테이너의 `overflow-hidden`.
- 조치: 자동완성 표시 중(`showOriginSuggestions || showDestinationSuggestions`)에만 `overflow-visible`, 그 외는 `overflow-hidden` 유지.
- 결과: 패널 접힘 여부와 관계없이 Start/End 자동완성 드롭다운 가시성 개선.

## 5) 현재 동작 명세 (최종)

### 상단 장소 검색
- 입력 디바운스 후 자동완성 목록 표시.
- 목록 선택 또는 검색 실행 시 지도 이동.
- 검색 위치 `P` 마커 표시.
- `P` 마커를 직접 클릭하면 제거.
- 이동 완료 시 상단 검색 패널 자동 닫힘.

### Route Settings Start/End
- 입력 시 Nominatim 자동완성 목록 표시.
- 키보드/마우스 선택 지원.
- 드롭다운 폭은 현재 확장값(`156%`) 적용.
- 자동완성 표시 중에는 상위 컨테이너 `overflow-visible`로 전환되어 잘림 최소화.

## 6) 사용자 영향
- 장소 검색과 경로 입력 자동완성의 사용성이 일관됨.
- 검색 완료 후 화면 가림이 줄어 주행/지도 확인 흐름이 자연스러워짐.
- 접힌 패널 상태에서도 드롭다운 확인이 가능해져 모바일 입력 피드백이 개선됨.

## 7) 리스크 및 후속 권장사항
- 드롭다운 폭이 큰 상태에서 초소형 화면에서는 좌우 경계 이탈 가능성이 있음.
- 필요 시 후속으로 `max-width`/`clamp()` 또는 Portal 렌더링 전환을 검토할 수 있음.
- 다만 현재는 기존 구조를 최대한 유지한 상태에서 요구사항 중심으로 최소 변경 적용함.
