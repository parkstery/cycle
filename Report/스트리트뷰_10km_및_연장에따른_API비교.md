# 10km 및 연장 시 — 현재 방식 vs 성능 최우선 API 호출 비교

## 공통 가정

- **샘플 간격**: 7m
- **현재 방식**: 200m 세그먼트 단위 프리페치 + 온디맨드 (세그먼트당 29 샘플, 샘플당 1~8회)
- **성능 최우선**: 전 구간 한 번에 프리페치, 샘플당 1회만 조회(1~2회)

---

## 1. 10km 구간 비교

### 현재 방식 (10km)

| 항목 | 계산 | 결과 |
|------|------|------|
| 세그먼트 수 | 10km ÷ 200m | **50개** |
| 총 샘플 수 | 50 × 29 | **1,450개** |
| **최소 호출** | 1,450 × 1 | **1,450회** |
| **일반적** | 1~2회/샘플 가정 | **약 1,450~2,900회** |
| **최대 호출** | 1,450 × 8 | **11,600회** |

### 성능 최우선 방식 (10km)

| 항목 | 계산 | 결과 |
|------|------|------|
| 총 샘플 수 | floor(10000/7) + 1 | **1,429개** |
| **최소 호출** | 1,429 × 1 | **1,429회** |
| **일반적** | 1~2회/샘플 | **약 1,429~2,858회** |
| **최대 호출** | 1,429 × 2 | **2,858회** |

### 10km 요약 비교

| 구분 | 현재 방식 | 성능 최우선 방식 |
|------|-----------|-------------------|
| **최소** | 1,450회 | 1,429회 |
| **일반적** | 약 1,450~2,900회 | 약 1,429~2,858회 |
| **최대** | **11,600회** | **2,858회** |
| **최대 시 차이** | — | 현재가 **약 4.06배** 더 많음 |

## 2. 연장이 늘어날 때 — 일반 식

경로 길이를 **L km** (L > 0) 라 두면:

### 현재 방식

| 항목 | 식 | 비고 |
|------|-----|------|
| 세그먼트 수 | ceil(1000×L / 200) = **5L** (L가 km 단위 정수일 때) | 200m 단위 |
| 총 샘플 수 | 5L × 29 = **145L** | |
| **최소 호출** | **145L** | |
| **최대 호출** | **145L × 8 = 1,160L** | |

### 성능 최우선 방식

| 항목 | 식 | 비고 |
|------|-----|------|
| 총 샘플 수 | floor(1000×L / 7) + 1 ≈ **143L** (L가 클 때) | 7m 간격 |
| **최소 호출** | **≈ 143L** | |
| **최대 호출** | **≈ 143L × 2 = 286L** | |

### 연장에 따른 대략 값 (정수 km)

| L (km) | 현재 최소 | 현재 최대 | 성능 최소 | 성능 최대 | 최대 시 비율 (현재/성능) |
|--------|-----------|-----------|-----------|-----------|---------------------------|
| 1 | 145 | 1,160 | 143 | 286 | **약 4.06** |
| 5 | 725 | 5,800 | 715 | 1,430 | **약 4.06** |
| 10 | 1,450 | 11,600 | 1,429 | 2,858 | **약 4.06** |
| 20 | 2,900 | 23,200 | 2,858 | 5,716 | **약 4.06** |
| 50 | 7,250 | 58,000 | 7,144 | 14,288 | **약 4.06** |
| 100 | 14,500 | 116,000 | 14,287 | 28,574 | **약 4.06** |

(최대 시 비율 = (145×8) / (143×2) = 1160/286 ≈ 4.06)

## 3. 연장에 따른 API 호출 코스트 차이

### 3.1 선형 비례

- 두 방식 모두 **경로 길이 L에 비례**해서 호출 수가 늘어남.
- **현재**: 최소 145L, 최대 1,160L  
- **성능 최우선**: 최소 ≈143L, 최대 ≈286L  

### 3.2 절대 차이 (회수)

- **최소** 구간: 145L vs 143L → 차이 **약 2L** (거의 동일).
- **최대** 구간: 1,160L vs 286L → 차이 **약 874L**  
  - 10km: 11,600 − 2,858 ≈ **8,742회** 현재가 더 많음  
  - 50km: 약 **43,700회** 더 많음  
  - 100km: 약 **87,400회** 더 많음  

→ 연장이 2배가 되면 **호출 수 차이도 약 2배**로 커짐.

### 3.3 비율 (현재 / 성능 최우선)

- **최소**: 145L / 143L ≈ **1.01** (거의 동일).
- **최대**: (1,160L) / (286L) ≈ **4.06** (연장과 무관하게 일정).

즉, **길이가 아무리 길어져도 “최악” 상황에서는 현재 방식이 성능 최우선 대비 약 4배 정도 더 호출**하는 구조가 유지됨.

### 3.4 코스트 관점 (요청 단가 동일 가정)

- API 요청 1회당 비용을 **c** 라 두면:
  - **현재 최대 코스트** ≈ **1,160 × L × c**
  - **성능 최우선 최대 코스트** ≈ **286 × L × c**
  - **차이** ≈ **(1,160 − 286) × L × c = 874 × L × c**

예: c = 0.01달러, 10km → 차이 ≈ 87.4달러, 100km → 약 874달러 (최악 시나리오 가정 시).

## 4. 정리

| 항목 | 내용 |
|------|------|
| **10km** | 현재 최대 **11,600회**, 성능 최대 **2,858회** → 현재가 약 **4배** 많음. |
| **연장** | 두 방식 모두 **L에 비례**; 차이(회수)도 **약 874×L** 로 선형 증가. |
| **비율** | 최대 시 **현재/성능 ≈ 4.06** 로, 연장과 무관하게 유지. |
| **코스트** | 요청 단가 동일 시, 연장이 길수록 **절대 코스트 차이**는 선형적으로 커짐. |

즉, **연장이 늘어날수록 두 방식의 API 호출·코스트 차이는 절대값으로는 커지지만, 비율(약 4배)은 일정**하게 유지됩니다.
