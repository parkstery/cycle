# 화면 회전(세로/가로) 적용 안내

## 적용한 설정

1. **manifest.json**  
   - `"orientation": "any"` — 세로/가로 모두 허용.

2. **index.html**  
   - manifest 링크: `?v=3` 로 캐시 갱신 유도.  
   - `<meta name="screen-orientation" content="any">` — 일부 환경에서 회전 허용 안내.  
   - 페이지 로드 시 `screen.orientation.unlock()` 호출 — 혹시 걸려 있던 방향 잠금 해제.

## 스마트폰에서 여전히 세로만 나올 때

### Android (Chrome, 홈 화면에 추가한 앱)

- **한 번만** 아래 순서로 진행해 보세요.  
  1. **홈 화면에서 앱 아이콘 길게 누르기** → “제거” 또는 “삭제”로 **앱 제거**.  
  2. Chrome에서 해당 사이트 접속 후 **주소창 옆 메뉴(⋮)** → **앱 설치** 또는 **홈 화면에 추가** 로 다시 추가.  
- 이렇게 하면 **새 manifest**(orientation: any, v=3)가 적용되어, 기기를 세로/가로로 돌리면 화면이 함께 전환됩니다.

### iOS (Safari, 홈 화면에 추가한 앱)

- iOS는 **manifest의 orientation을 사용하지 않습니다.**  
- 기본적으로 기기 방향에 따라 세로/가로가 바뀌므로,  
  - **회전 잠금**이 꺼져 있는지 확인하고,  
  - **홈 화면에서 추가한 앱**으로 실행 중인지 확인해 보세요.  
- 그래도 세로만 나오면: 기기 설정 → Safari(또는 해당 브라우저) → “방향 잠금” 등이 있는지 확인.

### 공통

- **기기 자체 회전 잠금**이 켜져 있으면 어떤 웹 설정으로도 가로 모드가 되지 않습니다.  
  - 제어 센터/설정에서 “회전 잠금” 또는 “방향 잠금”을 끄세요.

배포 후 위 설정으로 **새로 설치/추가**한 경우에는 세로·가로 모두 전환되며, 이미 설치된 앱은 **한 번 제거 후 다시 추가**하면 회전이 적용됩니다.
