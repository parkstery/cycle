# 20260329-하단 배너 반투명 띠 해결 확인 및 배경색 조정

## 1. 배경

- **증상(과거):** Android 가로 모드에서 WebView 콘텐츠와 네이티브 AdMob 배너가 겹치며, 하단에 **흰색 반투명 띠**가 광고 위에 얹혀 보이는 현상이 있었음.
- **Chrome Inspect 한계:** 배너는 DOM에 없고 네이티브 뷰이므로, 원인은 **뷰 합성 순서(z-order)** 와 **WebView/맵 내부 UI** 조합으로 좁혀 진행함.

## 2. 효과가 확인된 조치(마지막 단계 중심)

다음 조치를 적용한 뒤 **현장 확인 기준으로 반투명 흰 띠는 사라진 것으로 확인**됨.

| 조치 | 목적 |
|------|------|
| **`MainActivity`에서 WebView를 부모 `ViewGroup` 인덱스 0으로 이동** | AdMob 등 플러그인 뷰가 항상 WebView **위**에 그려지도록 고정. 회전 후 `bringChildToFront(마지막 형제)`만으로는 배너가 WebView 아래에 남는 경우를 제거. |
| **`WebView.setBackgroundColor`로 불투명 배경** | 투명 배경과 네이티브 레이어 합성 시 생기는 **알파 번짐·반투명 착시** 완화. |
| (선행) `App.tsx` 하단 `z-[5] bg-white` 전폭 띠 제거 | WebView가 배너 위에 그려질 때 흰 레이어가 광고를 덮는 경로 차단. |
| (선행) 맵 `overflow-hidden`, `.gm-style-cc` 등 스타일 조정 | 맵 내부 UI가 하단으로 비쳐 보이는 경우 완화. |

**결론:** 마지막 단계로 적용한 **WebView z-order 하단 고정 + 불투명 WebView 배경**이 반투명 띠 제거에 **실효가 있었음**을 스크린샷(2026-03-29)으로 재확인함.

## 3. 후속 조정(PM 요청): 배너 주변 검은 배경

- 불투명 배경을 **`Color.BLACK`** 으로 두면, 가로에서 배너가 화면보다 좁을 때 **좌우로 검은 띠**가 노출되어 UI와 대비가 큼.
- **대응:** 동일하게 **불투명**을 유지하되 배경색을 **`Color.WHITE`** 로 변경해, 배너 주변이 흰색으로 채워지도록 함. (합성 안정성 목적은 그대로, 색만 조정.)

## 4. 회귀 시 점검 순서

1. 가로/세로 전환 후 배너가 WebView에 가려지는지( z-order ).
2. WebView 배경이 다시 투명해지지 않았는지.
3. `App.tsx`에 전폭 흰 띠 레이어가 재도입되지 않았는지.
4. Google 맵 DOM 클래스 변경으로 `.gm-style-*` 오버라이드가 무효화되지 않았는지.
