# 260430-미니맵 3모드 처리과정 보고서

## 1) 배경 및 문제 정의
- 주행 중 Street View 전체화면 사용 시 좌상단 미니맵이 시야를 가려 몰입감과 가독성을 저해함.
- 기존 레이아웃 버튼은 `Minimize/Maximize` 2상태 토글 중심이라, "완전히 가리기(Hidden)" 요구를 충족하지 못함.

## 2) 목표
- 기존 `Show/Hide Street View` 제어(`isSvActive`)와 분리하여, 미니맵 레이아웃만 3상태로 순환 제어.
- 버튼 1개로 아래 순서를 반복 동작:
  - `split` -> `mini` -> `hidden` -> `split`

## 3) 설계 요약
- 상태를 토글 조합(`isSvFullScreen`, `isSvMapHidden`)에서 단일 상태머신으로 단순화.
- 신규 타입:
  - `SvMapLayoutMode = 'split' | 'mini' | 'hidden'`
- 파생 상태:
  - `isSvFullScreen = svMapLayoutMode !== 'split'`
  - `isSvMapHidden = svMapLayoutMode === 'hidden'`
- 버튼 클릭 핸들러는 현재 상태를 보고 다음 상태로 전이.

## 4) 구현 내용(App.tsx)
- `SvMapLayoutMode` 타입 및 `svMapLayoutMode` state 추가.
- 레이아웃 순환 핸들러 `handleCycleStreetViewLayout` 구현.
- 미니맵 컨테이너(`mapRef`) 스타일 분기에서 `hidden` 상태 시:
  - `opacity-0`, `pointer-events-none` 적용으로 완전 비노출.
- 기존 Street View on/off 핸들러는 유지하되, off 시 레이아웃만 `split`으로 초기화.
- 주행 시작/재시작 경로에서는 사용성 일관성을 위해 `mini`로 진입.

## 5) 사용자 체감 동작
- Street View 활성 상태에서 레이아웃 버튼을 누를 때마다:
  1. 분할(slit) -> 2. 소형 미니맵(mini) -> 3. 미니맵 숨김(hidden) -> 1. 분할
- Hidden 상태에서는 미니맵이 화면에 보이지 않음.

## 6) 빌드/배포 절차
- 코드 수정 후 로컬 빌드를 수행해 실패 여부 확인.
- 변경 파일만 커밋 후 원격 브랜치(`origin/dev2`)에 push.

## 7) 후속 점검 항목
- 실제 기기(특히 Android WebView)에서 상태 전환 시 맵 리사이즈/터치 충돌 여부 확인.
- 버튼 툴팁 문구를 "현재 상태 + 다음 동작" 기준으로 정교화 가능.
