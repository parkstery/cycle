# Cycle Simulator 앱 – 콘트롤 목록

| 구분 | 콘트롤 유형 | 위치/레이블 | 역할 | 주요 동작/상태 |
|------|-------------|-------------|------|----------------|
| **지도 상단** | Button | 지도 스타일 전환 (원형) | 지도 타입 변경 (hybrid ↔ 기본) | `handleToggleMapType`, `mapType === 'hybrid'` 시 강조 |
| | Button | 스트리트뷰 커버리지 표시 | 스트리트뷰 커버리지 레이어 on/off | `setShowCoverage(!showCoverage)` |
| | Button | 스트리트뷰 표시 | 스트리트뷰 패널 표시/숨김 | `setIsSvActive(!isSvActive)` |
| | Button | 스트리트뷰 전체화면 | 스트리트뷰 최대화/최소화 | `setIsSvFullScreen(!isSvFullScreen)` |
| **검색 바** | Button | 검색 토글 (Search/ChevronLeft) | 검색 입력 영역 펼침/접기 | `setSearchExpanded(!searchExpanded)` |
| | Input (text) | "Search place..." | 장소 검색어 입력 | `searchTerm`, Enter 시 `handlePlaceSearch()` |
| | Button | 검색 초기화 (X) | 검색어 지우기 | `handleClearSearch` |
| | Button (목록 항목) | 검색 기록 항목 | 이전 검색어로 다시 검색 | `handlePlaceHistoryClick(term)` |
| **경로 입력** | Button | 경로 설정 토글 (Waypoints/ChevronLeft) | 출발/경유/도착 입력 패널 펼침/접기 | `setRouteInputExpanded(!routeInputExpanded)` |
| | Input (text) | "Start (지명·주소 입력)" | 출발지 입력 + 자동완성 | `origin`, `setOrigin`, 출발지 제안 선택 |
| | Button | 출발지 제거 (X) | 출발지 필드 비우기 | `handleRemoveStart` |
| | Button (목록 항목) | 출발지 제안 항목 | 제안 중 하나를 출발지로 선택 | `handleSelectOriginSuggestion(item)` |
| | Button | 경유지 제거 (X) | 해당 경유지 삭제 | `handleRemoveWaypoint(idx)` |
| | Input (text) | "End (지명·주소 입력)" | 도착지 입력 + 자동완성 | `destination`, `setDestination`, 도착지 제안 선택 |
| | Button | 도착지 제거 (X) | 도착지 필드 비우기 | `handleRemoveEnd` |
| | Button (목록 항목) | 도착지 제안 항목 | 제안 중 하나를 도착지로 선택 | `handleSelectDestinationSuggestion(item)` |
| **속도** | Input (number) | Speed 숫자 | 속도(km/h) 직접 입력 | 10~70, `speedKmH`, blur 시 범위 클램프 |
| | Button | 속도 -1 km/h | 속도 1 감소 | `setSpeedKmH(prev => Math.max(10, prev - 1))`, 10 이하 시 비활성 |
| | Input (range) | 슬라이더 | 속도 10~70 범위 조절 | `speedKmH`, step 1 |
| | Button | 속도 +1 km/h | 속도 1 증가 | `setSpeedKmH(prev => Math.min(70, prev + 1))`, 70 이상 시 비활성 |
| **경로 액션** | Button | 출발↔도착 맞바꾸기 | 출발지와 도착지 스왑 | `handleSwapEndpoints` |
| | Button | 즐겨찾기 추가/내 경로 | 현재 경로 저장 또는 내 경로 패널 | `handleToggleFavorite`, `isSaved` 시 스타일 변경 |
| | Button | 경로 삭제 (Trash2) | 경로·마커 등 지도 오버레이 제거 | `clearMapOverlays` |
| **이동 수단** | Button | 자동차 (Car) | 자동차 경로로 계산 | `setMode(DRIVING)`, `calculateRoute(DRIVING, false)` |
| | Button | 자전거 (Bike) | 자전거 경로로 계산 | `setMode(BICYCLING)`, `calculateRoute(BICYCLING, false)` |
| | Button | 도보 (Footprints) | 도보 경로로 계산 | `setMode(WALKING)`, `calculateRoute(WALKING, false)` |
| | Button | Go | 경로 계산 후 시뮬레이션 시작(카운트다운) | `calculateRoute(mode, true)` 또는 `startSimulationOnly` |
| **내 경로** | Button | 내 경로 패널 펼침/접기 | My Routes 목록 표시/숨김 | `setHistoryExpanded(!historyExpanded)` |
| | Button | 저장된 경로 항목 | 해당 경로 로드 | `handleLoadFavorite(route)` |
| | Button | 저장 경로 삭제 (X) | 즐겨찾기에서 제거 | `handleDeleteFavorite(route.id, e)` |
| **고도·시뮬레이션** | Button | 고도 프로필 토글 | 고도 프로필 패널 펼침/접기 | `setElevationExpanded(!elevationExpanded)` |
| | Button | 시뮬레이션 재시작 | 같은 경로로 시뮬 재시작 | `restartSimulation` |
| | Button | 재생/일시정지 | 시뮬레이션 재생 또는 일시정지 | `handleToggleSimulation`, `simulation.isActive` |
| | Button | 시뮬레이션 정지 | 시뮬레이션 중단 | `handleStopSimulation` |
| | Button | 코칭 멘트 on/off | 코칭 멘트 재생 여부 | `setCoachingOn(!coachingOn)` |
| | Button | 배경 음악 on/off | 배경 음악 재생 여부 | `setMusicOn(!musicOn)` |
| **맵 클릭 팝업** | Button | 팝업 닫기 (X) | 클릭 위치 팝업 닫기 | `setClickedLocation(null)` |
| | Button | "START (A)" | 클릭 위치를 출발지로 설정 | `handleSetStart` |
| | Button | 경유지 추가 | 클릭 위치를 경유지로 추가 (최대 3개) | `handleAddWaypoint`, 3개일 때 비활성 |
| | Button | "END (B)" | 클릭 위치를 도착지로 설정 | `handleSetEnd` |
| **기타** | Button | About (i) | 앱 정보 모달 열기 | `setShowAbout(true)`, 우상단 고정 |

## 요약

| 콘트롤 유형 | 개수 | 비고 |
|-------------|------|------|
| Button | 40+ | 토글, 액션, 목록 선택, 아이콘 버튼 등 |
| Input (text) | 3 | 검색, 출발지, 도착지 |
| Input (number) | 1 | 속도(km/h) |
| Input (range) | 1 | 속도 슬라이더 |

*위치는 “지도 상단”, “검색 바”, “경로 입력”, “속도”, “경로 액션”, “이동 수단”, “내 경로”, “고도·시뮬레이션”, “맵 클릭 팝업”, “기타”로 구분했습니다.*
