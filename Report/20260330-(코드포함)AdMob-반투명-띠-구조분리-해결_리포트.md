## 20260330-AdMob-반투명-띠-구조분리-해결_리포트
### 1) 배경 / 증상
- Android 세로 모드에서 AdMob 배너가 표시될 때, 배너 구간과 겹쳐 보이는 “흰색 반투명 띠(바)”가 나타남
- 광고 DOM/CSS 문제가 아니라, 네이티브 뷰(AdView) 오버레이와 WebView 렌더링이 합성되는 과정에서 WebView 콘텐츠가 배너 구간과 섞여 보이는 현상으로 판단
### 2) 근본 원인(요약)
- `@capacitor-community/admob`의 배너 구현이 런타임에 AdView를 WebView와 같은 루트 컨테이너의 형제 overlay 구조로 추가
- 즉, CSS/색상/패딩/흐림(blur) 완화만으로는 “겹침 자체”를 근본적으로 제거하기 어려움
- 따라서 WebView가 배너가 올라오는 구간까지 그리지 않도록 **구조적으로 분리**해야 함
### 3) 해결 전략(우선순위)
- 정답: WebView 영역과 AdMob 배너가 겹치는 합성 구간을 구조적으로 제거(= 배너 높이만큼 WebView 그리기 영역 차단)
- 차선: 합성 클리핑(추가 브릿지/연동 필요)

4.2 MainActivity.java (배경 제어 제거 + z-order 개입 최소화)
android/app/src/main/java/com/liveonsoft/cycle/MainActivity.java

- 배경색 결정을 Java에서 덮어쓰지 않도록 `getWindow()`/`wv` 배경 제어 코드를 제거
- 구조 분리로 겹침이 원천 차단되므로, `stackNativeLayersBannerOnTop()`에서의 z-order 개입도 최소화 방향으로 정리
private void stackNativeLayersBannerOnTop(ViewGroup vg, WebView wv) {
    float density = getResources().getDisplayMetrics().density;
    float midZ = Math.max(16f, 12f * density);
    wv.setElevation(0f);
    wv.setTranslationZ(0f);
    try {
        vg.setClipChildren(true);
        vg.setClipToPadding(true);
    } catch (Throwable ignored) {
    }
    List<View> adHosts = new ArrayList<>();
    List<View> otherPlugins = new ArrayList<>();
    for (int i = 0; i < vg.getChildCount(); i++) {
        View c = vg.getChildAt(i);
        if (c == wv) {
            continue;
        }
        if (viewSubtreeContainsAdMobAdView(c)) {
            adHosts.add(c);
        } else {
            otherPlugins.add(c);
        }
    }
    for (View c : otherPlugins) {
        c.setElevation(0f);
        c.setTranslationZ(0f);
    }
    // AdView 호스트 관련 강제 z-order 개입을 최소화
    for (View c : adHosts) {
        c.setElevation(0f);
        c.setTranslationZ(0f);
    }
    for (View c : otherPlugins) {
        vg.bringChildToFront(c);
    }
    for (View c : adHosts) {
        vg.bringChildToFront(c);
    }
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.LOLLIPOP) {
        wv.setZ(0f);
        for (View c : otherPlugins) {
            c.setZ(midZ);
        }
    }
}

6) 결론
문제는 CSS/색/blur 조정이 아니라, AdMob 배너가 런타임에 WebView overlay 형식으로 삽입되는 구조적 특성에서 기인
해결의 근본은 WebView가 배너가 올라오는 구간까지 그리지 않도록 구조적으로 분리한 것
따라서 구조 분리 적용 후 반투명 띠가 재발하지 않게 되었음
7) 주의사항 / 향후 점검
placeholder 높이(118dp)가 광고 타입/기기에서 실제 배너 높이와 1:1로 매칭되는지 추가 기기에서 재검증 필요
만약 특정 기기에서 배너 주변에 약간의 여백/경계가 남으면 placeholder 높이만 조정하는 방식으로 보정 가능
