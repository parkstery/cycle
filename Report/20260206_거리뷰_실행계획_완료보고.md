## Phase 1

- **주행 중 실시간 거리뷰 검색 제거**: `else if (svServiceRef.current && !isSvSearching.current)` 블록 전체 삭제. 주행 중 `getPanorama` 호출 0회.
- **캐시 없을 때**: `!route.panoData?.length`이면 `setShowSvWarning(true)`.
- **갭 구간**: `panoData`는 있으나 현재 위치가 마지막 캐시 pano보다 30 포인트 이상 앞서면 `inGap`으로 `setShowSvWarning(true)`.
- **슬라이딩 prefetch**: 유지. 단, `toM = distAtLast + 400`, `intervalM: 10`으로 변경(Phase 3 반영).
- **상수**: `MAX_REALTIME_SV_ATTEMPTS` 주석에 Phase 1 이후 미사용 표기.

---

## Phase 2

- **상수**: `SV_PASS1_RADIUS_M = 50`, `SV_PASS1_MAX_ANGLE_DEG = 40`, `SV_PASS2_RADIUS_M = 120`, `SV_SCORE_DIST_WEIGHT = 0.6`, `SV_SCORE_ANGLE_WEIGHT = 0.4`, `SV_SCORE_ANGLE_DENOM_DEG = 90`.
- **preFetchStreetViewData**:
  - 1단계: `findStreetViewInDirection(..., 50, 40)` → 후보에 추가.
  - 2단계: 후보 없을 때만 `findStreetView(..., 120)` → description 필터 후 후보에 추가.
  - 후보를 `filtered`(실내 키워드 제외) 후, `score = 0.6*(1-d/maxD) + 0.4*(1-diff/90)`으로 최대 점수 1개만 선택해 `panoData`에 push.
- **반환**: `{ panoData, sampleCount: n }` (Phase 5용).

---

## Phase 3

- **segmentLength**: 2 → **10** (densifiedPath 보간 간격).
- **초기 prefetch**: `maxDistanceM: 200` → **300**, `intervalM: 7` → **10**.
- **슬라이딩**: `toM = distAtLast + 200` → **distAtLast + 400**, `intervalM: 10`.

---

## Phase 4

- **types.ts**: `PanoDataItem`에 `description?: string` 추가.
- **findStreetViewInDirection**: 반환 객체에 `description: data.location?.description ?? undefined` 포함.
- **상수**: `SV_INDOOR_KEYWORDS = /Shop|Indoor|Business/i`.
- **pass2**: `pass2.data.location?.description`이 키워드 포함 시 후보에서 제외.
- **필터**: `filtered = candidates.filter(c => !c.item.description || !SV_INDOOR_KEYWORDS.test(c.item.description))`, 점수 선택은 `filtered` 기준.

---

## Phase 5

- **types.ts**: `RouteInfo`에 `streetViewCoverage?: number`, `streetViewDisabled?: boolean` 추가.
- **상수**: `COVERAGE_MIN = 0.7`.
- **초기 prefetch 직후**: `coverage = panoData.length / sampleCount`, `setRoute(..., { panoData, streetViewCoverage: coverage, streetViewDisabled: coverage < COVERAGE_MIN })`.
- **슬라이딩 prefetch**: 반환 `{ panoData: nextPanos }` 구조로 호출부 수정.
- **UI**: `route?.streetViewDisabled`일 때 "이 구간은 거리뷰가 부족합니다." 배지 표시.
