## 2. 사용 설명서 (User Manual)

### 2.1 요약(앱 내·스토어용 짧은 설명)

- **한 줄:** 출발·도착을 정하면 경로와 고도 프로필을 보고, Street View로 실제 도로 화면을 보며 가상 라이딩을 즐기는 웹 앱입니다.
- **2~3줄:**  
  - 지도에서 출발지·도착지(및 경유지)를 설정하고, 자동차/자전거/도보 중 경로를 선택할 수 있습니다.  
  - 경로 확정 후 Go를 누르면 고도 기반 코칭과 함께 가상 주행이 시작되며, Street View를 켜면 실제 거리 화면을 보며 라이딩할 수 있습니다.  
  - 속도 조절, 일시정지, 즐겨찾기(My Routes) 등이 지원됩니다.

### 2.2 상세 사용 설명서

- 프로젝트 내 **`Report/User_Manual.md`** (또는 `Report/20260202-User_Manual.md`)에 상세 사용법이 있음.
- 배포 시 **앱 내 "도움말" 또는 "사용 방법"** 링크로 해당 문서를 웹에 공개된 페이지로 연결하거나, 앱 내 별도 화면으로 요약해 넣을 수 있음.

### 2.3 필수 안내 항목 (사용설명서에 포함 권장)

- 출발·도착·경유지 입력 방법 (검색 vs 지도 클릭)
- 경로탐색 vs Go 버튼 차이 (경로만 계산 vs 계산 후 바로 시뮬 시작)
- Car / Bike / Foot 모드 선택
- Street View 켜기·끄기 및 전체화면
- 속도 조절, 재생/일시정지/리셋
- 고도 차트 보기, My Routes(즐겨찾기) 사용
- PWA 설치 방법 (설치 가능한 경우)

## 3. Q&A (자주 묻는 질문)

| 질문 | 답변 (예시) |
|------|-------------|
| **무료로 쓸 수 있나요?** | 네. 앱 자체는 무료로 사용할 수 있습니다. 단, 인터넷 연결이 필요하고, Google Maps 등 외부 서비스 정책에 따릅니다. |
| **어디서 사용할 수 있나요?** | 웹 브라우저가 있는 기기(PC, 스마트폰, 태블릿)에서 접속해 사용할 수 있습니다. |
| **오프라인에서도 되나요?** | 아니요. 지도·경로·Street View 표시를 위해 인터넷 연결이 필요합니다. |
| **내 위치가 수집되나요?** | 앱은 사용자가 입력한 출발·도착·경로 정보만 사용하며, 별도로 사용자 위치를 수집하지 않습니다. (단, 브라우저·OS의 일반적인 접속 로그는 서버·CDN 정책에 따릅니다.) |
| **경로가 안 나와요.** | 해당 구간에 경로 데이터가 없거나, 일시적으로 서버(Google/OSRM) 오류가 있을 수 있습니다. 다른 출발·도착으로 시도하거나 잠시 후 다시 시도해 보세요. |
| **Street View가 안 나와요.** | 해당 도로에 Street View 촬영 구간이 없을 수 있습니다. 다른 경로를 선택하거나 Street View를 끄고 고도·경로만 보며 이용할 수 있습니다. |
| **모바일에서 느려요.** | Street View와 지도 동시 표시는 기기 성능에 따라 부하가 클 수 있습니다. Street View를 끄거나, 데스크톱에서 이용해 보세요. |

*(실제 배포 시 서비스 정책·기능에 맞게 문구를 수정해 사용하세요.)*

## 4. 주의사항·면책 (Disclaimer)

### 4.1 필수 면책 문구 (앱/스토어/About에 포함 권장)

- **목적:** 본 앱은 **교육 및 피트니스 엔터테인먼트 목적**으로만 제공됩니다.
- **이용 책임:** **사용자 본인의 책임 하에** 이용해 주시며, 운동 프로그램 시작 전 **전문의와 상담**하는 것을 권장합니다.
- **데이터 정확성:** 지도·경로·고도·Street View 등 데이터는 외부 서비스(Google, OSM 등)에서 제공하며, **정확성·완전성에 대해 보장하지 않습니다.**
- **운전·실제 주행:** 앱 내 경로·속도는 **가상 시뮬레이션**용이며, 실제 도로 주행·운전 시 법규와 안전 수칙을 준수해 주세요.

### 4.2 현재 구현 상태

## 6. 배포 전 체크리스트

### 6.1 환경·설정

| 항목 | 확인 내용 |
|------|-----------|
| **환경 변수** | `GOOGLE_MAPS_API_KEY` 설정 (Vercel 등 호스팅의 Environment Variables). 로컬은 `.env` 또는 `.env.local`. |
| **API 키 제한** | Google Cloud Console에서 해당 키에 **HTTP 리퍼러(도메인) 제한**, **Maps JavaScript API·Street View 등 필요한 API만** 활성화 권장. |
| **빌드** | `npm run build` 성공 여부, 배포 URL에서 지도·경로·Street View 동작 확인. |
