# 주행 시 화면 전환 후 맵 검은 화면 — 원인 분석 및 조치

**작성일:** 2025-02-04

---

## 1. 증상

- 주행 초기 **전면 맵**에서는 경로와 주행 시뮬레이션(마커 이동)이 정상 표시됨.
- **카운트다운이 끝나고** 화면이 Street View + 미니맵으로 전환되면, **맵 영역만 검게** 보이고 **경로(빨간선)와 주행 마커만** 보임.

---

## 2. 원인 분석

### 2.1 레이아웃 전환

- 카운트다운 종료 시 `setIsSvActive(true)`, `setIsSvFullScreen(true)` 호출.
- 맵 컨테이너가 **전면(absolute inset-0)** 에서 **미니맵(160×160px)** 으로 크기·위치가 바뀜.
- CSS `duration-500`으로 위치 등이 전환됨.

### 2.2 Leaflet 동작

- **타일 레이어(TileLayer)**: 컨테이너 크기·뷰포트에 맞춰 타일을 요청·그림. 컨테이너 크기가 바뀌면 `invalidateSize()` 등으로 다시 계산해야 함.
- **벡터 레이어(Polyline, Marker)**: 맵 좌표 기준으로 그리므로, 크기 변경에 상대적으로 덜 민감함.
- 전환 시 **타일 레이어만** 새 크기에 맞게 다시 그리지 못하고, **벡터(경로·마커)만** 그려져서 “배경만 검고, 경로/마커는 보이는” 현상이 발생한 것으로 판단.

### 2.3 결론

- **화면 전환(전면 맵 → Street View + 미니맵)** 에 따라 맵 컨테이너 크기가 바뀌는 순간, Leaflet **베이스 타일 레이어**가 새 크기로 갱신되지 않음.
- `invalidateSize()`만으로는 타일이 다시 그려지지 않는 경우가 있어, **타일 레이어를 제거 후 다시 부착**하여 강제로 리드로우하는 방식으로 대응함.

---

## 3. 조치 내용

1. **베이스 타일 레이어 ref 보관**  
   - `leafletBaseLayerRef`: 맵 생성 시 베이스 OSM 타일 레이어를 저장.

2. **맵 컨테이너 전환 종료 시**  
   - `onTransitionEnd`에서 기존처럼 `invalidateSize()`, `setView()` 호출.  
   - 이어서 **풀스크린 미니맵 상태**일 때, 베이스 타일 레이어를 `removeLayer` 후 `addLayer`로 다시 붙여 타일을 강제 리드로우.

3. **isSvFullScreen 변경 시**  
   - 기존 `isSvFullScreen` useEffect에서 550ms, 850ms, 1200ms에 `invalidateSize()`/`setView()` 유지.  
   - **650ms**에 베이스 타일 레이어 `removeLayer` → `addLayer` → `invalidateSize()` 추가하여, 전환 후 타일이 다시 그려지도록 함.

---

## 4. 기대 효과

- 카운트다운 종료 후 화면이 Street View + 미니맵으로 바뀌어도, **미니맵에 OSM 타일이 정상 표시**되고, 경로·마커와 함께 보이도록 함.
