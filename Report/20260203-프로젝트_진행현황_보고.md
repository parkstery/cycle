## 3. 구현 완료 현황

### 3.1 지도·경로 (WEB GIS) — 완료

- Google Maps 초기화, Places/Geometry/Elevation 라이브러리
- 경로 계산: Google Directions 1차 → OSRM 폴백 (BICYCLING/WALKING/DRIVING)
- 출발/도착/경유지 입력, 지도 클릭으로 START·WAYPOINT·END 설정
- 출발↔도착 스왑, 도로 스냅 좌표 유지(originLocationRef/destLocationRef)
- 경로·마커·커버리지 레이어(Street View 지원 구간 표시)
- 장소 검색, 최근 검색 5건, 검색 결과 지도 마커

### 3.2 Street View — 완료

- 시뮬레이션 경로 기준 파노라마 전환
- **점진적 로딩**: 초기 200m만 pre-fetch 후 주행 가능, 주행 중 300m 도달 시 다음 200m 온디맨드
- **주행 방향 필터**: 전방 ±90° 내 파노라마 우선
- **이중 버퍼링**: 전환 시 heading을 백그라운드에 적용 후 스왑 → 검은 화면·회전 끊김 최소화
- 풀스크린/50% 레이아웃, 미지원 구간 연속 실패 시 안내

### 3.3 시뮬레이션 — 완료

- 재생/일시정지/정지, 10~100 km/h 속도 조절
- 경로 방향 반영 마커, 고도 차트 ReferenceLine 동기화
- 경과 시간·주행 거리(1초 간격), 완주 시 자동 정지·TTS 완주 메시지

### 3.4 고도·운동 — 완료

- ElevationService 100 샘플, 경사 기반 소요 시간 보정
- Recharts 고도 프로필, 실시간 커서

### 3.5 AI 코칭 — 완료

- **주행 시작**: Gemini 1회 `getCourseBriefing` (코스 요약·전략, TTS)
- **주행 종료**: Gemini 1회 `getRideEncouragement` (격려 메시지, TTS)
- **주행 중**: 로컬 `getPredictiveCoaching` + `phraseManifest` + `audioCache` MP3 재생 (API 미사용, 트래픽 절감)
- 경사 → 저항 1~8, 액션(SIT/STAND/TUCK/PEDAL) 매핑, 실패 시 폴백 멘트

### 3.6 UX·부가 — 완료

- 내 경로(즐겨찾기) 최대 5개, 저장/로드/삭제
- 배경 음악(드롭박스 MP3), 지도 타입(roadmap/hybrid)
- 접이식 검색/경로/고도/히스토리 패널
- 경로탐색(돋보기)·Go 버튼 정렬·수동 경로 실행 정책 반영

## 7. 요약

- **핵심 시나리오**(경로 설정 → 고도 확인 → Street View 시뮬레이션 → AI 코칭)는 **전반적으로 구현 완료** 상태입니다.
- Street View는 점진적 로딩·방향 필터·캐시·이중 버퍼링으로 생략과 끊김을 줄였고, Gemini는 주행당 2회(시작 브리핑, 종료 격려)만 사용해 트래픽을 제어했습니다.
- **권장 개선**: `.env.example` 추가, `App.tsx` 컴포넌트/훅 분리, `@types/google.maps` 도입, 실시간 Geolocation·Bottom Sheet 등 로드맵 항목 검토.
