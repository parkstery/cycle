# Geocoder / Elevation / 지도 타일 오픈소스 대체 적용 여부 확인 보고

**확인일:** 2025-02-03  
**확인 항목:**  
1. Geocoder → Nominatim  
2. Elevation → Open-Elevation  
3. 지도 타일 → Leaflet + OSM  

---

## 결론: **세 가지 모두 미적용**

현재 코드는 **Google Geocoder**, **Google Elevation API**, **Google Maps(타일)** 를 그대로 사용하고 있으며, Nominatim / Open-Elevation / Leaflet+OSM 으로의 전환 작업은 **되어 있지 않습니다.**

---

## 1. Geocoder → Nominatim

| 항목 | 상태 | 근거 |
|------|------|------|
| **Nominatim 사용** | ❌ 미사용 | 코드·의존성 전역 검색 결과 `nominatim`, `openstreetmap.org` 호출 없음 (문서 언급만 존재) |
| **Google Geocoder 사용** | ✅ 사용 중 | `App.tsx` 에서 `google.maps.Geocoder()` 생성 및 `geocode({ location })` / `geocode({ address })` 호출 |

**코드 위치**
- `App.tsx` 155행: `geocoder = useRef<any>(null)`
- `App.tsx` 635행: `geocoder.current = new google.maps.Geocoder()`
- `App.tsx` 692행: 지도 클릭 시 `geocoder.current.geocode({ location: e.latLng }, ...)`
- `App.tsx` 1267행: OSRM 폴백 시 주소→좌표 `geocoder.current.geocode({ address: addr }, ...)`

---

## 2. Elevation → Open-Elevation

| 항목 | 상태 | 근거 |
|------|------|------|
| **Open-Elevation / OpenTopoData 등 사용** | ❌ 미사용 | `open-elevation`, `opentopodata` 등 검색 시 문서 언급만 있고, 실제 API 호출 코드 없음 |
| **Google Elevation 사용** | ✅ 사용 중 | `google.maps.ElevationService()` 및 `getElevationAlongPath` 호출 |

**코드 위치**
- `App.tsx` 157행: `elevationService = useRef<any>(null)`
- `App.tsx` 586행: Maps 스크립트 로드 시 `libraries=places,geometry,elevation`
- `App.tsx` 637행: `elevationService.current = new google.maps.ElevationService()`
- `App.tsx` 1170행: `const es = new google.maps.ElevationService()`
- `App.tsx` 1312행: `await es.getElevationAlongPath({ path, samples: 100 })`

---

## 3. 지도 타일 → Leaflet + OSM

| 항목 | 상태 | 근거 |
|------|------|------|
| **Leaflet 사용** | ❌ 미사용 | `leaflet`, `L.map` 검색 시 코드 내 사용처 없음 |
| **OSM 타일 사용** | ❌ 미사용 | 지도 타일 소스로 OpenStreetMap URL 사용하는 코드 없음 |
| **Google Maps 사용** | ✅ 사용 중 | `google.maps.Map`, `maps.googleapis.com` 스크립트 로드 |

**코드 위치**
- `index.html`: `preconnect` to `https://maps.googleapis.com`
- `App.tsx` 586행: `script.src = 'https://maps.googleapis.com/maps/api/js?key=...&libraries=places,geometry,elevation&...'`
- `App.tsx` 604행: `googleMap.current = new google.maps.Map(mapRef.current, { ... })`
- 전역적으로 `google.maps.*` (Directions, StreetView, Marker, Polyline, Geometry 등) 사용

---

## 4. 요약 표

| 대체안 | 적용 여부 | 현재 사용 중인 서비스 |
|--------|-----------|------------------------|
| Geocoder → **Nominatim** | ❌ 미적용 | Google Geocoder |
| Elevation → **Open-Elevation** | ❌ 미적용 | Google Elevation API |
| 지도 타일 → **Leaflet + OSM** | ❌ 미적용 | Google Maps JavaScript API (전체 지도 스택) |

---

## 5. 참고

- **OSRM** 경로 폴백만 이미 적용되어 있음 (Directions 실패 시 `router.project-osrm.org` 사용).
- Nominatim / Open-Elevation / Leaflet+OSM 도입 시에는 기존 Google 호출 제거·분기 처리 및 라이선스·사용 정책 확인이 필요함.
